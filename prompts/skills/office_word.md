# Word 文档生成

使用 `create_word_document` / `add_word_content` 等工具生成 Word 文档。工具详细参数见各自的 docstring。

---

## 强制流程

```
搜索调研 → 规划结构 → 用户确认 → 逐章节生成 → 交付
```

### 1. 搜索调研（不可跳过）
- **任何涉及文档内容生成的请求，一律先搜索 ≥3 轮**，包括但不限于：报告、方案、简历、合同、论文、计划书、说明书等
- 即使看起来是"模板"或"通用格式"，也需要搜索主流结构、排版规范、最佳实践作为参考
- 唯一可跳过搜索的场景：用户已提供完整文字内容，仅需排版（如"把这段文字排成 Word"）
- 搜索工具：`web_search`，收集最新格式规范、范文结构、行业标准
- 凭记忆编造内容或结构视为违规

### 2. 规划结构
基于素材规划文档结构：章节划分、每节要点、是否需要表格/图表。输出结构草稿给用户确认。

### 3. 用户确认
展示文档结构 + 预计篇幅，用户确认后再生成。

### 4. 逐章节生成
- 先调 `create_word_document` 创建文档骨架（标题 + 目录 + 首章）
- 再调 `add_word_content` 逐章节追加正文、表格、图片
- **路径规范**：`file_path` 必须使用 `get_workspace_path` 返回的工作区路径，禁止使用 `C:\Users\Default` 等系统路径

---

## 硬性约束

- **搜索先行**：任何文档生成都必须先搜索，模板也不例外
- **路径安全**：文件必须写入工作区（`get_workspace_path`），禁止写入系统目录
- **大纲确认**：禁止跳过用户确认直接生成全文
- **内容充实**：每章节至少 2-3 段正文或等效内容，禁止大段留空
- **数据溯源**：引用数据必须来自搜索素材，不可编造

## 工具速览

| 工具 | 用途 |
|------|------|
| `create_word_document` | 创建文档 + 写入标题/段落 |
| `add_word_content` | 追加 paragraph / heading / table / image |
| `extract_word_text` | 读取已有文档内容 |
| `search_replace_word` | 全文查找替换 |
| `batch_word_process` | 批量处理 Word 文档（提取信息/统计字数） |
