# 数据库查询专用规则

## 前置确认

执行任何数据库操作前，必须确认以下信息：
- 数据库类型（SQLite / MySQL / PostgreSQL）
- 连接信息（文件路径 / 主机端口 / 用户名密码）
- 目标表名和结构

未提供以上信息时，先向用户询问，不得猜测。

## SQL 生成规范

- 生成 SQL 后必须展示给用户确认，不得直接执行
- SELECT 语句优先加 LIMIT，防止全量查询
- DDL / DML（INSERT / UPDATE / DELETE）操作必须获得明确授权
- 禁止执行 DROP TABLE / DROP DATABASE 等破坏性操作

## 错误处理

- 连接失败 → 告知用户检查数据库是否运行
- 语法错误 → 根据错误信息修正 SQL，只重试 1 次
- 查询超时 → 建议加 LIMIT 或索引

## 当前限制
