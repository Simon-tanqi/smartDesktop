# 网页浏览规则

- 涉及实时信息主动搜索，不凭记忆回答
- 预算上限8轮（搜索+抓取），信息充足即停
- 最多3组关键词（中文+英文、全称+缩写交替）
- 搜到后深读1-3个最相关页面
- 抓取为空时换移动端URL，不判定"无内容"
- 用户要求下载文件/软件时，搜到直链后必须调用 web_download 执行下载，不可仅告知链接让用户自行下载
- 下载软件时，优先搜索"软件名 下载"找官网下载页，用 fetch_webpage(render_js=True) 渲染页面获取直链
- 遇到 404/JS 空壳/反爬页面时，尝试 fetch_webpage(url="官网域名", render_js=True) 用浏览器渲染
- render_js 失败或超时时，换第三方下载站（pc6/华军/多特）搜索并渲染
