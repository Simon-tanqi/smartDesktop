## search_files

**功能**：按文件名关键词递归搜索文件。默认搜索用户目录、桌面及 D/E/F 盘根目录，深度限制 3 层。

**何时使用**：
- 用户说"找一下发票文件"、"帮我找到周报"
- 不确定文件在哪个目录，只知道文件名大概叫什么
- 需要按扩展名过滤（如只搜 .pdf）

**何时不使用**：
- 需要按文件内容搜索 → 用 search_content
- 已知文件在哪个目录 → 用 scan_directory 查看目录内容
- 只想看项目代码结构 → 用 get_project_summary

**参数**：
- keyword: str（必填）文件名关键词，不区分大小写
- search_path: str（可选）指定搜索起始路径，不传则搜索用户目录及 D/E/F 盘
- file_extensions: list[str]（可选）过滤扩展名，如 `[".pdf", ".docx"]`
- max_results: int（默认 5）最大返回条数

**关键约束**：
- 深度限制 3 层，避免全盘扫描耗时
- 自动跳过系统目录（Windows / Program Files / node_modules / .git 等）
- 结果按找到顺序返回，不是按相关性排序

**错误处理**：
- 搜索路径不存在 → 跳过该路径，继续搜索其他候选路径
- 无匹配结果 → 返回空数组 `[]`
- 磁盘访问权限不足 → 跳过该目录，不报错
