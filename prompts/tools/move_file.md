## move_file

**功能**：移动文件到目标位置。目标可以是目录（文件保留原名）或完整新路径。

**何时使用**：
- 整理文件到分类目录
- 重命名并移动文件
- 将文件从临时位置移到正式目录

**何时不使用**：
- 需要保留原文件 → 用 copy_file
- 操作对象是目录 → 用 execute_command（move 命令）
- 批量移动 → 多次调用本工具

**参数**：
- source: str（必填）源文件绝对路径，含文件名和扩展名
- destination: str（必填）目标目录或完整目标路径
- overwrite: bool（默认 true）目标已存在时是否覆盖

**关键约束**：
- source 必须是已存在的文件，不能是目录
- 目标为目录时自动拼接原文件名
- overwrite=false 且目标已存在时，拒绝操作并返回错误

**错误处理**：
- 源文件不存在 → `{"success": false, "message": "源文件不存在: ..."}`
- 目标路径无效 → `{"success": false, "message": "目标路径无效..."}`
- 目标已存在且 overwrite=false → 返回冲突提示
