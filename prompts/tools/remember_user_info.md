## remember_user_info

**功能**：将用户信息保存到长期记忆中，跨会话持久化。

**何时使用**：
- 用户说"我叫张三"、"我的爱好是编程"
- 用户透露了长期目标、职位、偏好等信息
- 用户明确要求"记住这个"

**何时不使用**：
- 用户只是随口提到，没有要求记忆 → 不要主动调用
- 短期对话内容 → 由短期记忆（会话历史）自动管理
- 需要查询已有记忆 → 目前无独立查询工具，记忆会自动注入 system prompt

**参数**：
- key: str（必填）记忆字段名，支持：name / hobbies / long_term_goal / job_title / company
- value: str（必填）要记住的内容。hobbies 支持逗号或"和"分隔的列表

**关键约束**：
- key 必须在允许的字段列表中，否则返回错误
- 值会覆盖同 key 的旧值（不是追加）
- 数据存储在 long_term_memory.json

**错误处理**：
- key 无效 → `{"success": false, "message": "无效的记忆字段: ..."}`
- 保存成功 → 返回确认信息
