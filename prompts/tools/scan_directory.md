## scan_directory

**功能**：扫描指定路径下的第一层文件和文件夹，返回 JSON 数组。

**何时使用**：
- 不确定目录下有哪些文件时
- 需要查看真实目录结构再决定下一步操作
- 工具返回"找不到路径"后，先扫描父目录确认实际名称

**何时不使用**：
- 只需读已知文件内容 → 用 read_file
- 需要递归搜索文件 → 用 search_files
- 需要搜索文件内容 → 用 search_content

**参数**：
- path: str（必填）要扫描的目录绝对路径

**关键约束**：
- 只返回第一层，不递归
- path 必须是绝对路径
- 返回 JSON 数组，每个元素是文件/文件夹名

**错误处理**：
- 路径不存在 → 返回 "扫描失败: {错误信息}"
- 目录为空 → 返回空数组 `[]`，这是正常结果
- 权限不足 → 返回 "扫描失败: PermissionError"
