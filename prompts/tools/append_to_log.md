## append_to_log

**功能**：将内容追加保存到 Markdown 日志文件中，用于记录输出结果。

**何时使用**：
- 用户要求"把这个保存下来"
- 需要将 AI 生成的内容持久化到日志
- 记录操作结果供后续查看

**何时不使用**：
- 生成代码文件 → 用 write_file
- 需要结构化存储 → 用 write_file + JSON
- 只是临时输出、用户没要求保存 → 不用

**参数**：
- content: str（必填）要保存的内容
- filename: str（可选）日志文件名，默认按日期命名

**关键约束**：
- 追加写入，不会覆盖已有日志
- 文件保存在项目 logs 目录下
- 内容以 Markdown 格式保存

**错误处理**：
- 写入失败（权限/磁盘满）→ 返回异常信息
