# 经验内化功能 - 快速测试指南

## 🚀 测试步骤

### 1. 启动项目

```bash
cd "D:\PyCharm Project\MyAgent"
python app.py
```

浏览器打开 `http://localhost:8765`

---

### 2. 测试场景 1：Excel 处理 + 经验内化

**对话流程**：

```
用户：帮我处理这个 Excel 文件，统计每个部门的人数
Agent：（执行任务，使用 read_file、run_python 等工具）
用户：把这次处理的经验内化为新技能
```

**预期结果**：

✅ Agent 返回类似以下消息：

```
✅ 经验内化完成！

技能名称：**excel_department_stats**
版本：**1.0**
保存路径：`D:\PyCharm Project\MyAgent\prompts\skills\excel_department_stats.md`

你可以查看并修改这个技能文件，下次处理类似任务时我会自动使用这个技能。
```

✅ 文件 `prompts/skills/excel_department_stats.md` 被创建

✅ 文件内容包含版本号（`# 版本：1.0`）

### 3. 测试场景 2：代码生成 + 经验内化

```
Agent：（生成代码，提供脚本）

```

**预期结果**：

✅ Agent 返回成功消息，包含技能名称、版本、保存路径

### 4. 测试场景 3：触发词检测

**对话流程**：

```
用户：内化经验

```

**预期结果**：

✅ 以上所有消息都应该触发经验内化功能

✅ Agent 应该尝试从对话历史中提取步骤并生成技能

---

### 5. 验证生成的 Skill 文件

**检查点**：

1. **文件存在**：`prompts/skills/` 目录下有新的 `.md` 文件
2. **版本号**：文件开头包含 `# 版本：1.0`
3. **内容格式**：包含标题、工具使用、处理步骤、注意事项等部分
4. **编码正确**：文件使用 UTF-8 编码，无乱码

**示例验证命令**：

```bash
# 查看生成的技能文件
type "D:\PyCharm Project\MyAgent\prompts\kills\excel_department_stats.md"
```

---

### 6. 验证 Skill 自动生效

**测试步骤**：

1. 完成一次经验内化，生成 Skill 文件
2. 新建一个会话（点击前端的"新建聊天"按钮）
3. 发送类似的任务描述（例如："帮我统计 Excel 中每个部门的人数"）
4. 检查 Agent 是否加载了新生成的 Skill

**验证方法**：

- 查看日志文件（`logs/llm_calls/*/`），检查 System Prompt 中是否包含新技能的内容
- 或者在对话中直接问："你有哪些技能？"

## 🔍 故障排查

### 问题 1：经验内化未触发

**检查清单**：

- [ ] 用户消息中包含触发关键词（`内化经验`、`保存为技能` 等）
- [ ] `tools/skill_learning.py` 文件存在
- [ ] `backend/agent.py` 中已添加经验内化检测代码

**调试方法**：

在 `backend/agent.py` 的 Phase 1.5 处添加日志：

```python
print(f"[DEBUG] 检测经验内化意图: {user_message}")
print(f"[DEBUG] 检测结果: {skill_learning.is_skill_learning_request(user_message)}")
```

---

### 问题 2：技能生成失败（LLM 调用失败）

**检查清单**：

- [ ] LLM 配置正确（API Key、base URL 等）
- [ ] Ollama 正在运行（如果使用本地模型）
- [ ] 网络连接正常（如果使用在线 API）

**查看日志**：

```bash
# 查看最新的 LLM 调用日志
type "D:\PyCharm Project\MyAgent\logs\llm_calls\2026-06-29\*.json"
```

---

### 问题 3：技能文件未生成

**检查清单**：

- [ ] `prompts/skills/` 目录存在
- [ ] 有写入权限
- [ ] 文件名合法（无特殊字符）

**手动测试**：

```bash
cd "D:\PyCharm Project\MyAgent"
py -c "from tools import skill_learning; print(skill_learning.save_skill('test', '# 测试'))"
```

---

### 问题 4：前端未显示结果

**检查清单**：

- [ ] 浏览器控制台无 JavaScript 错误
- [ ] SSE 连接正常（Network 面板中查看）
- [ ] 后端返回了 `final` 或 `error` 事件

**浏览器调试**：

1. 打开浏览器开发者工具（F12）
2. 切换到 "Console" 标签
3. 发送触发经验内化的消息
4. 查看是否有错误日志
