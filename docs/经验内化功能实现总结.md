# 经验内化功能 - 完整实现总结

## ✅ 已修复的问题

### 问题 3.1：步骤提取逻辑脆弱 → ✅ 已修复

**原问题**：
- 仅凭字符串匹配判断是否为工具结果（`if "工具" in content and "返回" in content`）
- 硬截断最近 20 条消息（`recent_messages = messages[-20:]`）

**修复方案**：
- ✅ 使用消息角色（`user/assistant/tool`）判断类型
- ✅ 动态选择消息范围（基于任务相关性，查找任务开始标记如"帮我"、"请"等）
- ✅ 准确提取工具调用（从 `tool_calls` 或 `content` 中解析 JSON）
- ✅ 准确判断工具返回结果（检查 JSON 结构、常见前缀、错误信息）

**代码位置**：`tools/skill_learning.py` → `extract_task_steps_from_history()`

---

### 问题 3.2：LLM Prompt 质量问题 → ✅ 已修复

**原问题**：
- JSON 字符串盲截断到 3000 字符（`json.dumps(...)[:3000]`）
- Prompt 缺少对已有技能文件格式的参照

**修复方案**：
- ✅ 智能截断 JSON（按消息边界截断，不破坏结构）→ `_truncate_steps_intelligently()`
- ✅ 添加已有技能格式示例到 Prompt → `_load_example_skills()`
- ✅ 引导 LLM 遵循现有技能的风格（参考 `data_excel.md`、`code_generate.md` 等）

**代码位置**：`tools/skill_learning.py` → `generate_skill_with_llm()`

---

### 问题 3.3：版本号污染 Skill 正文 → ✅ 已修复

**原问题**：
- 版本号作为 `# 版本：1.0` 注入正文开头
- 两个 H1 标题出现在同一个文件里，浪费 Token

**修复方案**：
- ✅ 使用 YAML frontmatter 存储版本号（不污染正文）
- ✅ 技能文件格式：
  ```markdown
  ---
  skill_name: excel_department_stats
  version: 1.0
  created_at: 2026-06-29 22:00:00
  ---
  
  # 统计部门人数
  ...
  ```

**代码位置**：`tools/skill_learning.py` → `save_skill()`

---

### 问题 3.4：文件冲突策略不佳 → ✅ 已修复

**原问题**：
- 如果文件已存在，直接添加时间戳创建新文件（`excel_20260629_143025.md`、`excel_20260629_150801.md` 等）
- 缺少"版本覆盖"或"增量更新已有技能"的选项

**修复方案**：
- ✅ 自动备份旧版本到 `agent_skills/_backups/` 目录
- ✅ 覆盖原文件（保留最新版本）
- ✅ 预留接口：删除技能（`delete_skill()`）、更新技能（`update_skill()`）
- ✅ 支持版本自增（`1.0` → `1.1`）

**代码位置**：`tools/skill_learning.py` → `save_skill()`、`delete_skill()`、`update_skill()`

---

### 问题 3.5：触发词误判 → ✅ 已修复

**原问题**：
- 纯子串匹配（`if keyword in message_lower`）
- "把这次"是触发词，但用户说"帮我把这次的发票整理一下"会被误判

**修复方案**：
- ✅ 精确触发词：完整匹配（`"保存为技能"`、`"内化经验"` 等）
- ✅ 前缀触发词：出现在消息开头或结尾（`"把这次..."`、`"...将这次"`）
- ✅ 英文触发词：独立短语匹配（`\blearn\s+from\b`）
- ✅ 快速过滤：如果不包含任何过滤关键词（"技能"、"经验"、"学习"等），直接返回 `False`

**代码位置**：`tools/skill_learning.py` → `is_skill_learning_request()`

### 配置分离

#### 内置技能：`prompts/tools.yaml`

```yaml
domains:
  data_excel:
    keywords: ["excel", "表格", "统计"]
    tools: [read_file, run_python]
    description: "Excel 数据处理"

  code_generate:
    keywords: ["代码", "生成", "脚本"]
    tools: [write_code, run_python]
    description: "代码生成"
```

#### 学习技能：`agent_skills/agent_tools.yaml`（新增）

```yaml
domains:
  excel_department_stats:  # 自动学习的技能
    keywords: ["统计部门人数", "部门统计"]
    tools: []  # 留空，因为技能文件会注入所有工具
    description: "Excel 部门人数统计（自动学习）"
    version: "1.0"
    created_at: "2026-06-29 22:00:00"
    file_path: "agent_skills/excel_department_stats.md"

management:
  auto_register: true
  max_skills: 50
  version_policy: "increment"
```

## 🔄 完整生命周期：生成 → 保存 → 注册 → 加载

### 1️⃣ 生成（Generate）

**触发条件**：用户消息包含触发词（"把这次的经验保存为技能"、"保存为技能"等）

**处理流程**：
1. 检测经验内化意图 → `is_skill_learning_request()`
2. 提取任务处理步骤 → `extract_task_steps_from_history()`
3. 建议技能名称 → `suggest_skill_name()`
4. 生成 Skill 内容 → `generate_skill_with_llm()`

**代码位置**：`backend/agent.py` → Phase 1.5

---

### 2️⃣ 保存（Save）

**保存位置**：`agent_skills/` 目录

**文件格式**：
```markdown
---
skill_name: excel_department_stats
version: 1.0
created_at: 2026-06-29 22:00:00
---

# 统计部门人数

## 流程
1. 使用 read_file 读取 Excel
2. 使用 run_python 执行 pandas 统计
3. 返回统计结果

## 注意事项
- 确保文件路径正确
- 处理大文件时注意性能
```

**冲突处理**：
- 如果文件已存在，自动备份旧版本到 `agent_skills/_backups/`
- 覆盖原文件（保留最新版本）

**代码位置**：`tools/skill_learning.py` → `save_skill()`

---

### 3️⃣ 注册（Register）

**注册位置**：`agent_skills/agent_tools.yaml`

**注册内容**：
```yaml
domains:
  excel_department_stats:
    keywords: ["统计部门人数", "部门统计"]
    tools: []
    description: "Excel 部门人数统计（自动学习）"
    version: "1.0"
    created_at: "2026-06-29 22:00:00"
    file_path: "agent_skills/excel_department_stats.md"
```

**代码位置**：`tools/skill_learning.py` → `register_skill_to_yaml()`

---

### 4️⃣ 加载（Load）

**加载逻辑**（修改 `tools/__init__.py`）：
1. 从 `prompts/tools.yaml` 加载内置技能配置
2. 从 `agent_skills/agent_tools.yaml` 加载学习技能配置
3. 合并两个配置，进行域名匹配 → `match_domains()`
4. 从 `prompts/skills/` 加载内置技能文件
5. 从 `agent_skills/` 加载学习技能文件
6. 合并所有技能内容，注入 System Prompt → `_get_skill_prompts()`

**缓存机制**：
- 内置技能：`tools.yaml` 和 `skills/*.md` 使用 mtime 缓存自动失效
- 学习技能：`agent_tools.yaml` 和 `agent_skills/*.md` 使用 mtime 缓存自动失效
- **结论**：技能保存/注册后，下次对话自动生效，不需要重启！

**代码位置**：`tools/__init__.py` → `match_domains()`、`_get_skill_prompts()`、`_load_prompt()`
