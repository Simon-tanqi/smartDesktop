## 问题 1 & 2：关键词生成与注册

### 问题描述

1. **LLM Prompt 没有要求输出关键词**，导致注册时只能使用截断的任务描述作为关键词
2. **YAML frontmatter 不含 keywords 字段**，技能注册的关键词是"帮我处理这个 Excel 文件统计每个部门的人数"这类长句片段
3. **结果**：关键词几乎不可能命中用户后续查询，技能形同虚设

### 修复方案

#### 1. 修改 LLM Prompt（`tools/skill_learning.py`）

**新增要求**：
- LLM 必须在 YAML frontmatter 中包含 `keywords` 字段
- LLM 必须在正文开头添加 `KEYWORDS: 关键词1, 关键词2, 关键词3` 行（方便解析）
- 关键词生成要求：5-10 个关键词，简短（2-6 个字），包含任务类型、具体动作、对象

**Prompt 示例**：
```markdown
## 输出格式要求
直接输出 Markdown 内容（包含 YAML frontmatter），不要包含 ```markdown``` 代码块标记。

**必须包含以下部分：**

1. **YAML frontmatter**（必须包含 keywords）：
```yaml
---
skill_name: excel_department_stats
version: 1.0
created_at: 2026-06-29 22:00:00
keywords:
  - 统计部门人数
  - 部门统计
  - Excel统计
  - 人数统计
---
```

2. **KEYWORDS 行**（在正文开头，方便解析）：
在 YAML frontmatter 之后、# 标题之前，添加一行：
`KEYWORDS: 关键词1, 关键词2, 关键词3`

**关键词生成要求：**
- 生成 5-10 个关键词
- 包含：任务类型（如"Excel处理"）、具体动作（如"统计"）、对象（如"部门人数"）
- 关键词应该简短（2-6 个字），便于匹配
- 避免使用"帮我"、"请"等无关词汇
```

#### 2. 添加关键词提取函数（`tools/skill_learning.py`）

**新增函数**：`_extract_keywords_from_skill(content: str) -> list[str]`

**提取逻辑**（按优先级）：
1. 从 YAML frontmatter 的 `keywords` 字段提取
2. 从 `KEYWORDS: 关键词1, 关键词2` 行提取
3. 从 `# 标题` 提取（作为备选）

**代码**：
```python
def _extract_keywords_from_skill(content: str) -> list[str]:
    """从 LLM 生成的 Skill 内容中提取关键词。"""
    keywords = []
    
    # 方法 1：从 YAML frontmatter 提取
    yaml_match = re.search(r'^---\s*\n(.*?)\n---', content, re.DOTALL)
    if yaml_match:
        yaml_content = yaml_match.group(1)
        keywords_match = re.search(r'keywords:\s*\n((?:\s*-\s*[^\n]+\n?)*)', yaml_content)
        if keywords_match:
            keywords_text = keywords_match.group(1)
            for line in keywords_text.strip().split('\n'):
                match = re.search(r'^\s*-\s*(.+)$', line.strip())
                if match:
                    keywords.append(match.group(1).strip())
    
    # 方法 2：从 KEYWORDS 行提取
    if not keywords:
        keywords_match = re.search(r'KEYWORDS:\s*([^\n]+)', content)
        if keywords_match:
            keywords_text = keywords_match.group(1)
            keywords = [kw.strip() for kw in keywords_text.split(',') if kw.strip()]
    
    # 方法 3：从 # 标题提取（备选）
    if not keywords:
        title_match = re.search(r'\n#\s+([^\n]+)', content)
        if title_match:
            title = title_match.group(1).strip()
            keywords = [kw.strip() for kw in re.split(r'[\s，,、]+', title) if len(kw.strip()) >= 2]
    
    return keywords[:10]  # 最多返回 10 个关键词
```

## 问题 3：Chunked Tool Calls 的 Arguments 解析

### 问题描述

- 当工具调用使用**分块传输**时，`arguments` 是**增量字符串**而非 `dict`
- 直接访问 `tc.get("function", {}).get("arguments", {})` 会得到字符串，导致后续解包失败
- 需要添加 `isinstance(arguments, str)` 判断并 `json.loads` 兜底

### 修复方案

#### 修改步骤提取逻辑（`tools/skill_learning.py`）

**修改前**：
```python
if tool_calls:
    for tc in tool_calls:
        tool_name = tc.get("function", {}).get("name", "")
        tools_used.add(tool_name)
        steps.append({
            "role": "assistant",
            "content": content[:500],
            "tool_name": tool_name,
            "tool_args": tc.get("function", {}).get("arguments", {})  # ❌ 可能是字符串
        })
```

**修改后**：
```python
if tool_calls:
    for tc in tool_calls:
        tool_name = tc.get("function", {}).get("name", "")
        tools_used.add(tool_name)
        
        # 修复问题 3：处理 chunked tool_calls 的 arguments 可能是字符串
        arguments = tc.get("function", {}).get("arguments", {})
        if isinstance(arguments, str):
            try:
                arguments = json.loads(arguments) if arguments else {}
            except json.JSONDecodeError:
                arguments = {"raw": arguments}  # 如果解析失败，保留原始字符串
        
        steps.append({
            "role": "assistant",
            "content": content[:500],
            "tool_name": tool_name,
            "tool_args": arguments  # ✅ 确保是 dict 类型
        })
```

✅ **字符串类型的 arguments 被正确解析为 dict**，dict 类型的 arguments 保持不变。
