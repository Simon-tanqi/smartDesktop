## 问题 4：`_generate_fallback_skill` 无 YAML keywords 字段

### 问题描述

- 降级后关键词靠标题分词，质量偏低
- YAML frontmatter 不包含 `keywords` 字段

### 修复方案

**修改 `_generate_fallback_skill` 函数**（`tools/skill_learning.py`）：

```python
def _generate_fallback_skill(task_info: dict) -> str:
    """生成降级的 Skill 内容（当 LLM 调用失败时使用）"""
    now = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    
    # 从任务描述中提取基础关键词
    task_desc = task_info['task_description'][:50]
    tools = task_info.get('tools_used', [])
    
    # 生成关键词列表
    keywords = []
    
    # 从任务描述分词提取关键词
    words = re.split(r'[\s，,、。.!？?"\"]+', task_info['task_description'])
    
    # 无意义词过滤列表
    stop_words = {'帮我', '请', '我想', '能否', '这个', '一下', '处理', '好吗', '呢', '啊', '吧', '呀'}
    
    for w in words:
        w = w.strip()
        if 1 <= len(w) <= 6 and w not in stop_words:
            keywords.append(w)
    
    # 添加工具名作为关键词
    for t in tools[:2]:
        if t not in keywords:
            keywords.append(t)
    
    # 从工具名生成派生关键词
    for t in tools[:1]:
        if t == 'read_file' and '文件' not in keywords:
            keywords.append('文件')
        elif t == 'run_python' and '脚本' not in keywords:
            keywords.append('脚本')
        elif t == 'web_search' and '搜索' not in keywords:
            keywords.append('搜索')
    
    # 去重并限制数量
    seen = set()
    unique_keywords = []
    for kw in keywords:
        if kw not in seen:
            seen.add(kw)
            unique_keywords.append(kw)
    keywords = unique_keywords[:8]
    
    # 构建 YAML frontmatter（包含 keywords）
    keywords_yaml = '\n'.join(f'  - {kw}' for kw in keywords) if keywords else '  - unknown'
    keywords_line = ', '.join(keywords) if keywords else 'unknown'
    
    lines = [
        f"---",
        f"skill_name: {task_desc}",
        f"version: 1.0",
        f"created_at: {now}",
        f"keywords:",
        keywords_yaml,
        f"---",
        f"",
        f"KEYWORDS: {keywords_line}",
        f"",
        ...
    ]
```

**生成的降级 Skill 示例**：
```markdown
---
skill_name: 帮我处理这个Excel文件，统计每个部门的人数
version: 1.0
created_at: 2026-06-30 07:18:33
keywords:
  - read_file
  - run_python
  - 文件
---

KEYWORDS: read_file, run_python, 文件

# 帮我处理这个Excel文件，统计每个部门的人数
...
```

## 问题 5：YAML frontmatter 正则在正文含 `---` 时误匹配

### 问题描述

正则 `r'^---\s*\n(.*?)\n---'` 会误匹配正文中的 `---` 分隔线。

### 修复方案

**改进正则表达式**（`tools/skill_learning.py`）：

```python
# 修改前（会误匹配）
yaml_match = re.search(r'^---\s*\n(.*?)\n---', content, re.DOTALL)

# 修改后（只匹配文件开头的 frontmatter）
yaml_match = re.match(r'^---\s*\n(.*?)\n---\s*\n', content, re.DOTALL)
```

同时改进 KEYWORDS 行提取正则：
```python
# 修改前（包含 KEYWORDS: 前缀）
keywords_match = re.search(r'KEYWORDS:\s*([^\n]+)', content)
if keywords_match:
    keywords_text = keywords_match.group(1)

# 修改后（正确捕获冒号后面的内容）
keywords_match = re.search(r'KEYWORDS:\s*(.+)', content)
if keywords_match:
    keywords_text = keywords_match.group(1).strip()
```

### 测试结果

```

Extracted keywords: ['关键词1', '关键词2']

PASS: YAML frontmatter regex correctly ignores --- in body
```
