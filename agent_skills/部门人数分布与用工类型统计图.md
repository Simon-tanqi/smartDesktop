# Excel图表生成与自动更新

在 Excel 中生成堆积柱状图（区分正式工、实习生），并将图表嵌入到源文件的新 Sheet 中，确保数据变动时图表自动更新。

## 流程

1. **读取 Excel 文件**
   - 使用 `read_file` 工具读取用户指定的 `.xlsx` 文件路径
   - 确认数据结构：列名应包含「部门」「正式工」「实习生」等字段

2. **数据预处理（如需）**
   - 使用 `run_python` 执行 pandas 操作：
     - 检查列名是否规范，必要时重命名
     - 确保「正式工」「实习生」列为数值类型
     - 计算「总人数」列（正式工 + 实习生）

3. **在源文件新增 Sheet 并嵌入图表**
   - 使用 `run_python` 执行 openpyxl 操作：
     - 加载工作簿：`openpyxl.load_workbook(file_path)`
     - 新建 Sheet（如命名为「人数分布图」）
     - 将数据（部门、正式工、实习生）写入新 Sheet 的单元格（从 A1 开始）
     - 使用 `openpyxl.chart.BarChart` 创建堆积柱状图：
       - 类型：`grouping="stacked"`
       - 系列：正式工、实习生
       - 类别：部门
     - 将图表插入新 Sheet
     - **关键**：图表数据源必须引用新 Sheet 中的单元格（如 `=人数分布图!$A$1:$C$N`），而非硬编码数值，这样原数据变动后图表会自动更新
     - 保存工作簿：`wb.save(file_path)`

4. **验证与反馈**
   - 确认文件保存成功
   - 告知用户图表所在 Sheet 名称及自动更新特性

## 工具使用最佳实践

- **read_file**：仅用于确认数据结构，不要全量读取大文件
- **run_python**：执行 openpyxl 和 pandas 操作，确保环境已安装 `openpyxl`（如未安装，先 `!pip install openpyxl`）
- **文件路径**：使用用户提供的绝对路径，避免相对路径歧义

## 注意事项

- **图表自动更新**：必须通过公式引用单元格实现，不能使用静态数据
- **Sheet 命名**：避免与已有 Sheet 重名，可加时间戳或序号（如「人数分布图_1」）
- **数据格式**：确保「正式工」「实习生」列为数值，否则图表可能无法正确显示
- **保存模式**：使用 `openpyxl.load_workbook` 加载后直接 `save`，不要使用 `pd.ExcelWriter` 的 `mode='a'`，以免破坏已有图表
- **错误处理**：若文件被占用或路径不存在，先提示用户检查文件状态

## 常见错误

- 图表数据源使用了硬编码数值 → 改为引用单元格
- 忘记安装 openpyxl → 在 run_python 中先执行 `!pip install openpyxl`
- 图表插入后未保存 → 确保 `wb.save()` 执行
- 新 Sheet 名称冲突 → 使用 `wb.sheetnames` 检查并生成唯一名称
